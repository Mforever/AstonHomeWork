# React Homework 3

## 🚀 Описание проекта
React приложение с модальным окном, комментариями и фильтрацией постов.

## ✨ Функциональность
- Модальное окно с compound components
- Комментарии со сворачиванием/разворачиванием
- Фильтрация постов по длине заголовка
- Оптимизация с useMemo и useCallback
- Космический дизайн с анимациями

## 🛠️ Технологии
- React 18
- TypeScript
- Vite
- CSS Modules

## 📦 Установка

```bash
# Клонировать репозиторий
git clone https://github.com/DmitryRudenko/react-homework-3.git

# Установить зависимости
npm install

# Запустить в режиме разработки
npm run dev
